## Rules that never bend

- Store money as **integer paise**, never as floats.
- Ledger postings are **append-only**. Fix a mistake with a reversal entry.
- Every endpoint that moves money takes an **idempotency key**.
- Kafka and callback consumers are **idempotent**, because delivery is at-least-once.
- A DB write and its event go through the **outbox**. Never write and then publish.
- Agent spending limits live **in the payment service**, not in the prompt.
- API keys go in **`.env`**, which is never committed.
